# Developer Certificate of Origin

Webmana uses the [Developer Certificate of Origin (DCO)](https://developercertificate.org/)
version 1.1. By contributing, you certify the statement below for every commit.

Sign off every commit with `git commit -s`, which appends a line:

```
Signed-off-by: Your Name <you@example.com>
```

```
    are public and that a record of the contribution (including all
    personal information I submit with it, including my sign-off) is

```
